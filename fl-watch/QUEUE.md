## Каждый круг: triage\*.json
Бот кладет сюда каждый новый свежий заказ FL.ru (серые и занятые уже отсечены). Поля: id, title, text (полное ТЗ), url, budget_rub, responses, age_h, safe_deal, score, why, persona (похожие кейсы из Persona, бот уже запросил их сам).
Файлы не переносишь и не удаляешь: решение пишешь в `verdict\<имя json без .json>.txt` (`ok` или `skip`, через двоеточие короткая причина, например `skip: дизайн сайта`), бот сам уберет заказ из очереди.
Для каждого файла triage\*.json, у которого еще нет verdict:
1. Прочитай json, поле persona используй как похожие кейсы. Там «Persona недоступна»: решай без нее.
2. Реши, подходит ли заказ. Подходит: задача решается стеком Михаила (Python, парсинг, браузерная автоматизация/ZennoPoster, AI-агенты и LLM, Telegram-боты, интеграции CRM и API, ClickHouse/SQL, дашборды) или в Persona есть похожий кейс. Не подходит: дизайн, 1С/Битрикс, PHP/WordPress/Tilda как основная работа, мобильные приложения, видео, тексты, SEO/директ, учебные работы, железо и инженерия, заказы за копейки (меньше ~3 000 ₽ при заметном объеме), серое (авторег, обход защит, персональные данные физлиц, доверенные лица, накрутки). Сомневаешься, но задача на Python, AI/LLM, Telegram или интеграции = подходит, решение за Михаилом. Остальное при сомнении не подходит.
3. Не подходит: запиши `verdict\<имя>.txt` вида `skip: причина в несколько слов`, больше ничего.
4. Подходит: создай `outbox\<имя>.md` (markdown):
   - первая строка строго `#order=<id>`
   - `# <заголовок заказа>`
   - строка: бюджет · отклики · сколько часов назад · безопасная сделка да/нет
   - строка строго `Итог: ~N ч, N ₽, N дней` (часы, цена по 1 600 ₽/ч не выше бюджета, срок). Бот берет ее в подпись в Telegram, без нее в подписи не будет оценки.
   - `## Оценка`: чем подходит (1-2 строки, похожий кейс без личного: финансы, переписка, имена из Persona не переносить), риски и что уточнить, часы по этапам, цена по 1 600 ₽/ч (не выше бюджета заказчика), срок с учетом основной работы ~5 ч/день
   - `## Вариант 1 (короткий)`, `## Вариант 2 (с планом работ)`, `## Вариант 3 (с вопросом)`: готовые тексты отклика. У каждого строка «Поля: стоимость N ₽, срок N дней». Стиль: первая фраза про задачу заказчика, коротко, без «—», без «!», «е» вместо «ё», без подписи. Последняя строка каждого варианта: «По оплате: откликаюсь на карту физлица, но при необходимости работаем по безопасной сделке FL.ru и можем оформить через юрлицо/бухгалтерию.» Опыт не выдумывать, где нужен кейс с цифрами, ставь [ВПИСАТЬ].
   Потом запиши `verdict\<имя>.txt` вида `ok: чем подходит в несколько слов`.
