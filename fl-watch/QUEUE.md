# Очередь отчетов FL Watch (для CLI-сессии Claude Code)

Запуск: в D:\Codex\fl_watch выполнить `claude`, затем `/loop 2m обработай очередь по QUEUE.md`.

Каждый круг:
1. Посмотри `queue\*.json`. Пусто = круг окончен, ничего не пиши.
2. Для каждого файла (поля: title, text, url, budget_rub, responses, age_h, score, why, reply_to) напиши отчет по-русски, обычным текстом без markdown:
   - суть заказа в 2 предложениях;
   - риски и что уточнить у заказчика;
   - оценка в часах и цена по 1 600 ₽/ч, не выше бюджета заказчика; срок с учетом основной работы ~5 ч/день;
   - черновик отклика: коротко, по делу, первая фраза про задачу заказчика, без «—», без «!», «е» вместо «ё», без подписи. Последней строкой: «По оплате: откликаюсь на карту физлица, но при необходимости работаем по безопасной сделке FL.ru и можем оформить через юрлицо/бухгалтерию.»
   - Опыт не выдумывать. Где нужен кейс с цифрами, ставь [ВПИСАТЬ].
   Опыт Михаила: 11 лет в автоматизации и парсинге (ZennoPoster, Python), AI-агенты и LLM, Telegram-боты, ClickHouse/Metabase, интеграции CRM. Серые заказы (авторег, обход защит, персональные данные физлиц) не берем: в отчете так и пиши.
3. Сохрани отчет в `outbox\<то же имя>.md`. Первая строка строго `#reply_to=<reply_to из json>`, дальше: заголовок, ссылка url, затем отчет. Потом удали или перенеси json из `queue\` в `queue\done\`.
4. Ничего не отправляй на FL.ru и в Telegram сам: отчеты из outbox отправляет fl_watch.py.
