# Очередь FL Watch (для CLI-сессии Claude Code)

Запуск: в D:\Codex\fl_watch выполнить `claude`, затем `/loop 2m обработай очередь по QUEUE.md`.
Ничего не отправляй на FL.ru и в Telegram сам: всё из outbox\ отправляет fl_watch.py.

## 1. Отчеты по кнопке (queue\*.json)
Поля: title, text, url, budget_rub, responses, age_h, score, why, reply_to. Напиши отчет по-русски, обычным текстом без markdown:
- суть заказа в 2 предложениях;
- риски и что уточнить у заказчика;
- оценка в часах и цена по 1 600 ₽/ч, не выше бюджета заказчика; срок с учетом основной работы ~5 ч/день;
- черновик отклика: коротко, по делу, первая фраза про задачу заказчика, без «—», без «!», «е» вместо «ё», без подписи. Последней строкой: «По оплате: откликаюсь на карту физлица, но при необходимости работаем по безопасной сделке FL.ru и можем оформить через юрлицо/бухгалтерию.»
- опыт не выдумывать; где нужен кейс с цифрами, ставь [ВПИСАТЬ]. Для фактов опыта используй Persona (см. ниже).
Сохрани в `outbox\<имя>.md`, первая строка строго `#reply_to=<reply_to>`, дальше заголовок, url, отчет. json перенеси в `queue\done\`.

## 2. Сверка всех свежих заказов с Persona (triage\*.json)
Бот кладет сюда каждый свежий заказ без фильтра (серые уже отсечены). Заказы с оценкой от 5 бот прислал сам, их тут нет.
Для каждого файла:
1. Запроси Persona: POST http://127.0.0.1:8766/retrieve, заголовок X-API-Token из D:\Persona\client.env (значение не выводить), в запросе заголовок и первые 500 символов ТЗ. Если API не отвечает, решай без Persona и отметь это.
2. Реши, подходит ли заказ хоть как-то: в найденных кейсах есть похожая работа, либо задача решается стеком Михаила (Python, парсинг, браузерная автоматизация/ZennoPoster, AI-агенты и LLM, Telegram-боты, интеграции CRM и API, ClickHouse/SQL, дашборды). Дизайн, 1С/Битрикс, PHP/WordPress/Tilda, мобильные приложения, видео, тексты, SEO, учебные работы = не подходит. Серое (авторег, обход защит, персональные данные физлиц) = не подходит.
3. Подходит: создай `outbox\<имя>.md`, первая строка строго `#order=<id>`, дальше коротко: «FL (Persona): <заголовок>», бюджет, отклики, возраст; 1–2 строки, чем подходит и какой похожий кейс нашелся (без личного: финансы, переписка, имена людей из Persona не переносить).
4. Любой исход: перенеси json в `triage\done\`.
