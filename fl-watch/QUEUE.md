Сам ничего не отправляй ни на FL.ru, ни в Telegram: файлы из outbox\ отправляет fl_watch.py. Форму отклика на FL.ru не заполнять никогда, откликается Михаил сам.

## Каждый круг: triage\*.json
Бот кладет сюда каждый новый свежий заказ FL.ru (серые и занятые уже отсечены). Поля: id, title, text (полное ТЗ), url, budget_rub, responses, age_h, safe_deal, score, why.
Для каждого файла:
1. Запроси Persona: POST http://127.0.0.1:8766/retrieve, заголовок X-API-Token из D:\Persona\client.env (значение не выводить), в запросе заголовок и первые 500 символов ТЗ. API не отвечает: решай без Persona.
2. Реши, подходит ли заказ. Подходит: задача решается стеком Михаила (Python, парсинг, браузерная автоматизация/ZennoPoster, AI-агенты и LLM, Telegram-боты, интеграции CRM и API, ClickHouse/SQL, дашборды) или в Persona есть похожий кейс. Не подходит: дизайн, 1С/Битрикс, PHP/WordPress/Tilda как основная работа, мобильные приложения, видео, тексты, SEO/директ, учебные работы, железо и инженерия, заказы за копейки (меньше ~3 000 ₽ при заметном объеме), серое (авторег, обход защит, персональные данные физлиц, доверенные лица, накрутки). Сомневаешься = не подходит.
3. Не подходит: просто перенеси json в `triage\done\`, никаких файлов.
4. Подходит: создай `outbox\<имя>.md` (markdown):
   - первая строка строго `#order=<id>`
   - `# <заголовок заказа>`
   - строка: бюджет · отклики · сколько часов назад · безопасная сделка да/нет
   - `## Оценка`: чем подходит (1-2 строки, похожий кейс без личного: финансы, переписка, имена из Persona не переносить), риски и что уточнить, часы по этапам, цена по 1 600 ₽/ч (не выше бюджета заказчика), срок с учетом основной работы ~5 ч/день
   - `## Вариант 1 (короткий)`, `## Вариант 2 (с планом работ)`, `## Вариант 3 (с вопросом)`: готовые тексты отклика. У каждого строка «Поля: стоимость N ₽, срок N дней». Стиль: первая фраза про задачу заказчика, коротко, без «—», без «!», «е» вместо «ё», без подписи. Последняя строка каждого варианта: «По оплате: откликаюсь на карту физлица, но при необходимости работаем по безопасной сделке FL.ru и можем оформить через юрлицо/бухгалтерию.» Опыт не выдумывать, где нужен кейс с цифрами, ставь [ВПИСАТЬ].
   Потом перенеси json в `triage\done\`.
